# FiTrack – Train Smart. Move Better. Live Stronger. 🏃‍♂️🚴‍♂️🏊‍♂️

**FiTrack** is a modern all-in-one fitness and activity platform designed to help people track their workouts, analyze performance, set goals, compete with others, and build a consistent active lifestyle.

From running and cycling to swimming, hiking, tennis, kayaking, winter sports, strength workouts, and more — FiTrack brings your activities, progress, challenges, community, and fitness tools together in one platform.

---

## 🚀 Overview

FiTrack combines **activity tracking, performance analytics, social features, competitions, training tools, health-oriented utilities, and premium features** into a single ecosystem.

The platform is designed for both individual athletes and people who enjoy training with friends, participating in team competitions, and being part of an active community.

### What FiTrack can help you do

- 🏃 Track workouts and outdoor activities
- 📍 Record routes using interactive maps
- 📊 Analyze performance and training statistics
- ❤️ Monitor heart-rate data and training zones
- ⚖️ Track body weight and progress
- 🎯 Follow structured running plans
- 🏆 Participate in Team Races and competitions
- 🥇 Earn achievements and reach milestones
- 👥 Communicate with other athletes through Club
- 🗺️ Complete location-based challenges with Conquer
- 🧠 Access advanced fitness and training intelligence
- 💎 Unlock additional functionality with Premium
- 📸 Save and share workout photos and activity results
- 🔐 Manage your personal account and activity history

# 🎯 Core Features

## 🏃 Activity Tracking

FiTrack supports multiple types of physical activities, allowing users to record and analyze different forms of training.

### Supported activities include:

- 🏃 Running
- 🚴 Cycling
- 🏋️ Workout / Strength Training
- 🎾 Tennis
- 🛶 Kayaking
- 🥾 Hiking
- 🚶 Walking
- 🏊 Swimming
- ⛷️ Winter Sports

Depending on the activity, FiTrack can record relevant metrics such as:

- Duration
- Distance
- Pace
- Speed
- Calories
- Intensity
- Route
- Elevation
- Training information
- Activity type
- Personal statistics

Each activity is stored in the user's account and can be reviewed later.

---

# 🗺️ Interactive Maps & Routes

FiTrack provides map-based tracking for outdoor activities.

Users can:

- Record GPS routes
- View activity paths
- Analyze routes
- Track distance and movement
- Explore locations
- Visualize activity data directly on maps

The platform uses modern mapping technologies including **Leaflet**, **React Leaflet**, and **MapLibre GL**.

Maps are integrated into different parts of the platform, including activity tracking and challenge functionality.

---

# ❤️ Heart Rate & Training Zones

FiTrack is designed with heart-rate-based training in mind.

The platform can work with heart-rate information to help users better understand training intensity and cardiovascular load.

Training zones can be used to distinguish between different effort levels and make workouts more structured.

The project is also designed to support integration with external heart-rate sensors such as **Polar H10** through compatible environments.

# 🗺️ Conquer

**Conquer** is a location-based challenge experience built around maps and exploration.

Instead of simply recording workouts, Conquer encourages users to explore locations and complete challenges.

The feature combines:

- Interactive maps
- Location-based challenges
- Progress tracking
- Exploration
- Competition
- Achievements

Conquer is available as part of the FiTrack Premium ecosystem.

# ⚖️ Weight Control

FiTrack includes a dedicated **Weight Control** section for users who want to monitor changes in body weight and connect their weight goals with their active lifestyle.

Users can track:

- Current weight
- Weight changes
- Progress over time
- Personal goals

Different tiers provide different levels of access to advanced FiTrack functionality.

# 👤 Personal Account

Every user has a personal account where their FiTrack data and activity history are managed.

The account system supports:

- Registration
- Authentication
- Personal profile
- Activity history
- Saved workouts
- Premium status
- Personal statistics
- Account management

Authentication and user data are powered by **Firebase**.

# 🔐 Authentication & Data

FiTrack uses **Firebase Authentication** and **Cloud Firestore** for user authentication and application data.

The platform is designed around authenticated user accounts and protected user-specific data.

Firebase is used for functionality such as:

- User authentication
- Account management
- Activity storage
- Premium information
- User-generated content
- Team and community functionality
- Application data

---

# ☁️ Cloud Media

FiTrack integrates **Cloudinary** for working with user-generated media.

This allows the platform to handle:

- Workout photos
- Activity images
- User-generated media
- Image uploads
- Cloud-based media storage

This architecture keeps media management separate from the core application database.

# ⚡ Modern Frontend Architecture

FiTrack is built as a modern React application using a component-based architecture.

The application is organized into reusable components, pages, contexts, utilities, trackers, and feature-specific modules.

The architecture is designed to make it possible to continue expanding FiTrack with new activities, challenges, analytics, and social functionality without rebuilding the platform from scratch.
